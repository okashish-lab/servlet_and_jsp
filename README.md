# servlet_and_jsp

A simple Java Servlet and JSP project built with Maven.

## Project contents

- A Servlet that greets a visitor by name
- JSP pages for the home page and greeting
- Maven WAR packaging

## Build

```bash
mvn clean package
```

Deploy `target/servlet-and-jsp.war` to a Servlet 4.0-compatible container such as Apache Tomcat 9.
